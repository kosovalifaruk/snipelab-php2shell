# Lisans durumu

Bu yayına henüz MIT, Apache, Creative Commons veya başka bir açık lisans atanmamıştır. Mevcut rapordaki lisans durumu korunmuştur. Public GitHub deposu olarak erişime açılması, açık kaynak lisansı seçildiği anlamına gelmez.

Lisans belirlenirse kod ve belgeler için geçerli kapsam açıkça yazılmalı; README, rapor ve bu dosya birlikte güncellenmelidir. Üçüncü taraf araştırma yazıları, PHP/Docker/Nginx imajları ve GitHub Actions kendi koşullarına tabidir. Bu depoya üçüncü taraf araştırma yazılarının veya imajlarının kopyaları eklenmemiştir; kaynak bağlantıları raporda ve docs/SOURCES.md içindedir.

GitHub başvurusu: https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository
