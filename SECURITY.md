# Güvenlik ve test kapsamı

Laboratuvar, PHP'nin eski ve yamalı sürümlerini karşılaştırır. Kaynaklarda belirtilen iki CVE için bağımsız UAF/RCE PoC'si sağlamaz. Tanılama ve OOM endpoint'leri yalnız ayrılmış laboratuvar içindir.

Rutin kurulum ve belge hataları GitHub Issues üzerinden bildirilebilir. Parola, anahtar, üretim logu, bellek dökümü veya kişisel veri içeren bulguları public issue içine koymayın. Hassas bildirimde repo sahibinin resmî iletişim kanalını kullanın; özel güvenlik bildirimi etkinleştirilmişse GitHub Security içindeki özel raporlama yolunu seçin.

Desteklenen referans: rapor/laboratuvar sürümü 3.0 ve yayın paketi 3.0.4. Burada bir hizmet seviyesi veya müdahale süresi taahhüt edilmez.
